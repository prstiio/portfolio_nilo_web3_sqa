# Evidence Register (critical thinking)

Every number or claim shown in `README.md`, reports, a CV, or a profile must have a row here. If you cannot fill the "How to reproduce" cell, delete the claim.

| Claim | Value | Source (file / CI run) | How to reproduce | Date checked |
|---|---|---|---|---|
| EXAMPLE: Automated UI tests | 0 | `sqa/web-ui-playwright/tests/` | `npx playwright test --list` | YYYY-MM-DD |
| EXAMPLE: AI-test precision | n/a | `sqa/ai-testing/ai-test-log.csv` | `python sqa/ai-testing/precision.py` | YYYY-MM-DD |
| EXAMPLE: Requirements covered | n/a | `sqa/01-planning/`, `sqa/02-manual/` | `python scripts/portfolio_status.py` | YYYY-MM-DD |
| TODO | | | | |

Rule of thumb: the claim and the evidence must be one command or one link apart.
