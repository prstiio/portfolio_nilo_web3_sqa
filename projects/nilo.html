NILO

One product, two lenses. The same evidence is explained differently for each audience.

Everything on this page marked EXAMPLE came from a draft and has not been verified. Replace it with your own observations, with dates, before publishing.

Build lens (Web3)

Goal

Let Web3 features complement a Web2 foundation without disrupting the main experience.

Contribution EXAMPLE

  • Wallet Preview: connection status.
  • Read-only address, network, balance.
  • Documented limits: no transaction execution.

Stack: Next.js, React, TypeScript, EIP-1193. More on the Web3 page.

Quality lens (SQA)

Goal

Evaluate the main flows for function, layout, and responsiveness, and report findings with evidence.

Scope

  • Open the home page; navigate to the Web3 section.
  • Wallet unavailable: is the state explained clearly?
  • Desktop and mobile viewports.
  • Page response and horizontal overflow.

Manual vs automated: state which is which. Do not claim automation that does not exist.
