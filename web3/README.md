# Web3 Builder portfolio

The page is [`index.html`](index.html). This README is the source checklist for what that page may claim.

| Claim | Evidence required before it goes on the page |
|---|---|
| "Wallet Preview works" | Demo link or screen recording, with date |
| "Read-only" | Link to the code path showing no transaction is sent |
| "On-chain" | Deployed testnet address and explorer link; otherwise say "none yet" |
| Tech stack | Link to `package.json` or the repo |

Rules: testnet or local only; no private keys or seed phrases anywhere in the repo; never call something production-ready without evidence. How I test Web3 code: [`../sqa/web3-testing/`](../sqa/web3-testing).
